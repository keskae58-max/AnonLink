# AnonLink

Stealth privacy layer — silences tracking systems across Instagram, Threads, TikTok, and other platforms. Built for GitHub Pages.

## Features

- **Glassmorphism UI** — thin-stroke glass panels with backdrop blur
- **Stealth routing** — outbound links fragmented, shuffled, and resolved only on click (no plaintext in DOM)
- **Chrome-only gate** — blocks Instagram/Facebook/TikTok in-app browsers; prompts reopen in Chrome
- **LilaVoss profile layer** — fancy display name, circular pfp, rounded Connect tab
- **Admin config panel** — edit profile, links, platforms, effects, browser rules

## Quick Start

```bash
# Create admin account + encode channel link
npm run create-admin

# Local preview
npm run serve
# → http://localhost:8080
```

## Admin CLI

```bash
npm run create-admin
# or with flags:
node scripts/create-admin.js --username admin --password yourpass --channel "YOUR_CHANNEL_URL"
```

After running, open the site and click **⚙** (or visit `?config=1`) to unlock the config panel.

## GitHub Pages Deploy

1. Push this repo to `keskae58-max/AnonLink`
2. Go to **Settings → Pages**
3. Source: **Deploy from branch** → `main` → `/ (root)
4. Save — site live at `https://keskae58-max.github.io/AnonLink/`
